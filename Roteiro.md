# Roteiro Github
- Criar a sua conta (github.com)
  - Habilitar autenticação de dois fatores
  - Criar repositório com o mesmo nome de usuário (portfólio)
    - Personalizar o README.md

- Criação Repositório (seu projeto)
  - Licença 
  - Público/Privado
  - README.md

- Branch
  - main
  - Criar novas branches para modificações no código não "quebrar" a branch main

- Acesso ao código
  - Download arquivo ZIP
  - Efetuar Clone do repo
  - Editar o código no CodeSpaces (Visual Studio Web)

- Editar o README.md

- Settings
  - Adicionar colaboradores
  - Gerenciar permissões de acesso
  - $$\color{red}{\text{Danger Zone}}$$
    - $$\color{red}{\text{Delete Repositório}}$$

- Issues
  - Criação, resposta e fechamento
  - Milestone
      - Criação de issues
      - Acompanhamento

- Pull Requests
  - Gestão (aceite->Merge), recusa
  - Milestone

- Git (linha de comando)
  - git clone <url.git>
  - git status 
  - git add . ou git add <nome_arquivo>
  - git commit -m "mensagem"
  - git push
  - git pull
  - git log [--oneline]
  - git diff
